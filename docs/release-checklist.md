# Release checklist

This checklist is for the v1.0.0 research-preview snapshot.

## Before tagging

- Check package metadata.
- Run the test workflow.
- Run the quick-start commands from a fresh clone.
- Review public docs for private details.
- Review the demo output for personal information.
- Check that dry-run is still the default.
- Check that example configuration uses placeholder values.

## Notes

The first public snapshot is intentionally small. It documents one working weekly monitoring workflow before adding broader presets or dashboard features.
